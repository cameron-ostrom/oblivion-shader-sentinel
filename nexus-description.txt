[size=4][b]Know when the game is compiling shaders — and when it's safe to play.[/b][/size]

Oblivion Remastered shows its shader compilation progress bar [i]exactly once[/i], on first launch. Every recompile after that — GPU driver update, game patch — runs completely silently. The game sits at a screen that looks frozen, people alt-F4 it halfway through, and anyone who starts playing too early gets the stutter-fest.

Shader Sentinel fixes that with a small overlay in the corner of the game window, styled to match the game's own menus:

[list]
[*][b]Compiling Shaders…[/b] — with a live elapsed timer, while compilation is running
[*][b]Shaders Ready — completed in X:XX[/b] — the moment it's safe to play
[*][b]Shaders Ready — no compiling needed[/b] — about 20 seconds after launch when there was nothing to do (the usual case)
[/list]

The notice fades after a few seconds and the tool closes itself. Zero configuration, nothing running between game sessions, nothing to remember.

[size=4][b]Requirements[/b][/size]
[list]
[*]UE4SS for Oblivion Remastered (it starts Shader Sentinel with the game — most script-mod setups already have it)
[*]Windows 10/11 — no other runtimes needed
[/list]

[size=4][b]Installation[/b][/size]
Install with Vortex like any other mod, or manually drop the ShaderSentinel folder into ...\OblivionRemastered\Binaries\Win64\ue4ss\Mods\. Uninstalling leaves nothing behind — the tool writes no files, no settings, and no registry entries.

No UE4SS? You can instead set the game's Steam Launch Options to:
[code]"<path to>\OblivionShaderSentinel.exe" %command%[/code]

[size=4][b]What the exe actually does (read before trusting a random exe)[/b][/size]
Shader Sentinel is a single small external program. It does [b]not[/b] inject into the game, hook anything, or touch any game files. It detects compilation from the outside by watching two things: the game process's CPU usage, and write activity in your GPU driver's shader cache folders. When both go quiet, compilation is over. The overlay is a plain transparent always-on-top window — the same mechanism Steam and Discord notifications use. No network connections, nothing written to disk, and it exits by itself when done.

[b]The complete source code ships in the archive[/b] (one C# file, one Lua file) and builds with the compiler already installed on every Windows machine — run Source\build.cmd and you're running your own build instead of mine.

[size=4][b]Known limits[/b][/size]
[list]
[*]Reports busy vs. done, not a percentage — the driver doesn't expose how many shaders remain. "Done" is the part that matters.
[*]You may see a split-second console flash at game launch (the launcher script starting the exe).
[*]The overlay needs borderless/windowed mode (the game's default). In exclusive fullscreen nothing can draw on top.
[*]Tested on NVIDIA. AMD and Intel cache paths are implemented but unverified — reports welcome.
[*]Homemade .NET exes occasionally trip antivirus false positives. If yours complains, build from the included source.
[/list]
